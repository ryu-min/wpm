# Полный испанский каталог

Снимок Duome Spanish from Russian, представление by skill от 17 ноября 2026 года, получен 24 ноября. Источники и SHA-256 каждого HTML-файла находятся в `sources/metadata.json`. `sources/vocabulary.json` сохраняет 7 061 исходную запись 303 тем. HTML сохраняется для независимого воспроизведения извлечения.

Восемь модулей содержат 10, 31, 30, 60, 50, 50, 36, 36 тем. Для первых 131 тем сопоставление с реальными разделами один к одному, для следующих 172 тем — по пять Lesson 1–5. Все 991 имён DebugName проверяются. Список слов относится к целому диапазону, точное распределение внутри пяти уроков источник не предоставляет.

`normalization.json` содержит явное решение для каждой уникальной исходной формы. Сохранены проверенные решения первого модуля. Глагольные формы сопоставлялись с таблицей лемм и каноническими переводами каталога проекта. Омографы, например существительное и глагол, требуют содержательного решения. Отклонённые автоматические предложения не вносятся в каталог. Независимая экспертная лингвистическая редактура всего корпуса ещё не выполнена. Русские значения преимущественно передают краткий перевод источника. Канонический target принадлежит только первой теме, последующие появления записаны как повторы. Альтернативные ответы задаются только явными редакторскими решениями после отдельной проверки равнозначности. Совпадение русского текста само по себе альтернативу не создаёт.

`provenance.json` сохраняет решения всех строк, исходные формы и переводы, идентификатор владельца и опубликованной пары. `manifest.json` содержит иерархию и ссылки на descriptors в `datasets/`. Пустые после дедупликации темы сохраняются с пустой ссылкой.

Повторить сборку и офлайн-проверку из корня проекта можно командами `python3 scripts/build_spanish_course.py` и `python3 scripts/validate_spanish_course.py --self-test`. Внешние зависимости Python не требуются. Полнота утверждается относительно снимка публичного словаря, состав всех упражнений курса не доступен.

Для обновления выполните `python3 scripts/refresh_spanish_course_sources.py --download`. Команда загружает три страницы по URL metadata, записывает новые SHA-256 и извлекает vocabulary.json. Затем вручную сверяйте версии снимков и добавляйте решения новых форм в normalization.json. Для воспроизведения извлечения из сохранённого HTML выполните `python3 scripts/refresh_spanish_course_sources.py`. Изменение количества тем или Lesson блокирует публикацию до сверки структуры. После содержательной сверки обновите версии и SHA-256, затем повторите проверки.


Module `title` is the Spanish introductory phrase following that module's
heading in the preserved `structure.html` snapshot. The generator extracts all
eight phrases and the validator checks each phrase against its source module.
These labels accompany stable module ids and leave the vocabulary unchanged.
