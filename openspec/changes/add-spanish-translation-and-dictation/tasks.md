## Результаты исправлений и приёмки — раунд 2

Все три замечания первого независимого ревью исправлены:

1. Отмена аудио при работе UI остаётся асинхронной. Владение активными и отменёнными заданиями, JoinHandle и дочерними процессами сохраняется до очистки. Перед выходом и в Drop выполняется shutdown: остановка и ожидание дочерних процессов, ограниченное ожидание работников. Запись stdin вынесена из управляющего цикла. Новый E2E оставляет shell живой ещё 2 секунды после выхода wpm, проверяет PID через kill -0 непосредственно после WPM_EXITED и отсутствие отложенного завершения звука. Проверены и воспроизведение, и readiness; PASS. Закрытие PTY не используется как доказательство остановки аудио.
2. По уточнённым planner артефактам Result, завершённый по длине, принимает последовательное дополнение последней графемы combining-знаками без временного окна. Точность и WPM пересчитываются при замороженном elapsed; иная клавиша запечатывает результат, Backspace не возвращает редактирование, таймер закрывает ввод окончательно. E2E сравнивает одну порцию и раздельные порции с паузой 200 мс: Typing café с U+0301 даёт 100%, ES «кофе café» с U+0308 даёт 89% в обоих случаях. Unit-проверки подтверждают замороженное время, перерасчёт числителя WPM и границы таймера, Backspace и стрелки. Короткая задержка для угадывания конца Unicode не применяется.
3. Checked показывает аудиостатус. E2E успешный звук → верный ответ → ошибочный F2 → успешный F2 подтверждает видимые ошибку и восстановление, неизменные счётчики. В терминале 80×24 все строки доступны.
