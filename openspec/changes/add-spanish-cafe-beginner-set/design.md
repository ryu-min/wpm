# Design

## Context

Актуализировано 16 ноября 2026 в рамках [remove-dictation](../remove-dictation/proposal.md). История реализации и прежней приёмки сохранена в [tasks.md](tasks.md); отменённые аудиопроверки не объявлены выполненными. Эти действующие артефакты не требуют восстановления удаляемого режима.

Точный материал остаётся в `specs/spanish-cafe-beginner-set/spec.md`; последующая миграция data-driven-exercise-datasets уже задала единый descriptor. SQLite и `VocabularyEntry` общие с остальным испанским Translation. Узкая политика нечувствительного регистра требовалась только удалённому диктанту.

## Goals / Non-Goals

**Goals:** сохранить маленький самостоятельный набор, канонический текст, полный ввод пар и пользовательские данные.

**Non-Goals:** импорт Duolingo, аудио, варианты фраз с пропуском yo, изменение A1–C2, новая схема БД или отключение проверки регистра Translation.

## Decisions

### Единый ресурс и канонический текст

Использовать существующий descriptor `resources/datasets/ru_es_cafe_beginner.json` с id `ru_es_cafe_beginner`, level `beginner`, профилем `spanish-phrases`. Стабильные id записей и точная таблица 31 пары сохраняются; пересечения с A1–C2 допустимы. Нормализация исходных заметок в `Sergio` и `España` относится к подготовленному контенту, не к перезаписи пользовательской БД.

Общий seed добавляет только отсутствующий набор транзакционно. Не создавать отдельные таблицы, реестр или ветку по имени; профиль определяет доступность в Translation. Описание происхождения остаётся в `resources/ru_es_catalog.md` и README.

### Печать фраз

Translation показывает полную пару и сохраняет регистр, пробелы, ES-диакритику и RU/ENG-физические клавиши. `Me llamo Sergio` нельзя превращать в строчную строку перед проверкой; `Espana` остаётся разрешённым вводом для `España`. Enter вводит границу пар, Backspace позволяет вернуться через неё. Исключение регистра и подсказки скрытого ответа отменены; возвращать их в общий language нельзя.

### Приёмка

Сохраняются проверки точных 31 записей, id/NFC/пробелов и отсутствия кириллического произношения в испанском поле. Валидатор шести уровней остаётся строгим и не включает кафе как седьмой уровень. E2E проверяют новую/старую БД дважды, все пути выбора Translation, сохранение настроек и ввод двух фраз до результата 100% в любом случайном порядке; неверный регистр остаётся ошибкой. Общие проверки профилей могут использоваться вместо отдельного тестового файла словаря.

Историческая аудиопроверка 2.5 не выполнена и отменена remove-dictation. Действующая delta больше не содержит требования «Диктант фразы без угадывания регистра»; будущая синхронизация сохраняет только набор и Translation.

## Risks / Trade-offs

- Короткий набор ошибочно принят за сертифицированный курс → описывать оригинальную тему без заявления о точном Duolingo/CEFR.
- Старое диктантное исключение ослабляет Translation → сохранять строгий регистр и регрессионный сценарий.
- Общие тесты теряют проверку поставляемого контента → сверять полный descriptor и сохранять проверку 31 пары.

## Migration Plan

Схема и строки SQLite сохраняются. Новый набор добавляется только при отсутствии, локальные записи не заменяются. Удаление диктантных настроек управляется remove-dictation и не требует удаления кафе. Архивирование и закрытие старой аудиоприёмки не выполняются.
