# Proposal

## Why

В `Typing` и `Translation` различие регистра сейчас считается ошибкой, даже когда пользователь хочет тренировать скорость и правильные буквы без нажатия Shift. Нужна отдельная сохраняемая настройка для каждого из этих режимов с сохранением прежнего поведения по умолчанию.

## What Changes

- Добавить `Ignore case: On/Off` в секции настроек `Typing` и `Translation`; начальное значение и значение при отсутствии поля в старом JSON — `Off`.
- При `On` принимать различия регистра во всём упражнении, включая обе стороны переводной пары, сохраняя исходное написание образца и согласованность подсветки, Accuracy и WPM.
- Применять настройку выбранного режима при каждом доступном способе запуска и Restart, независимо от набора и настройки конвертации раскладки.
- Сохранить действующие правила RU/ENG-клавиш, испанской диакритики, Unicode, неверных букв, пробелов и пунктуации; игнорирование регистра дополняет разрешённые соответствия.

## Capabilities

### New Capabilities

- `typing-case-policy`: независимая пользовательская политика регистра для `Typing` и `Translation`, её сохранение, применение при запуске и согласованная оценка.

### Modified Capabilities

Нет изменений требований, уже находящихся в `openspec/specs/`: действующий контракт `keyboard-layout-conversion` сохраняется. Строгий регистр испанского ввода и `Translation` дополнительно описан в ещё не архивированных изменениях `add-spanish-translation-and-dictation`, `add-spanish-cafe-beginner-set` и `data-driven-exercise-datasets`. Новая capability задаёт явное исключение только при `Ignore case: On` в двух выбранных режимах; при `Off` сохраняется прежнее поведение. Порядок дальнейшей синхронизации этих контрактов описан в `design.md`.

## Impact

- `src/domain/settings.rs`, `src/ui/settings.rs` и JSON настроек: два необязательных булевых поля и две строки UI, сохранение и отмена черновика.
- `src/domain/typing.rs`, `src/ui/typing.rs`, `src/app/mod.rs`: политика сессии и единая оценка символов для экрана и статистики; при необходимости отдельный вспомогательный алгоритм в `src/domain/language.rs` без изменения действующего строгого алгоритма.
- `tests/e2e/`, необходимая поддержка проверки ANSI-стилей в `tests/e2e/common/mod.rs`, предметные тесты и `README.md`: приёмка настроек, ввода и границ совместимости, описание поведения.
- Формат и содержимое наборов, SQLite и зависимости Cargo не требуют изменений.
