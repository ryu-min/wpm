- Терминальные проверки выполнены на macOS/Unix через `script`, с изолированными `TestDataDir`/`WPM_DATA_DIR`. У процесса тестируемого приложения снимается унаследованный `NO_COLOR=1`, чтобы проверить фактический цвет ячеек; пользовательское окружение и реализация приложения не меняются.
