## Результаты приёмки

Проверки выполнены на macOS arm64. Терминальные сценарии используют Unix PTY. Установка обеих команд на Windows включена в CI.

| Требования | Подтверждение |
| --- | --- |
| Источник, распределение, нормализация и прежний словарь | Восемь модулей, 303 темы, 991 раздел, 7 061 исходная строка и 4 903 канонические единицы. В первом модуле учтены 208 строк и 177 единиц. Валидатор сверяет сохранённые страницы и отклоняет 11 ошибочных вариантов. Повторный офлайн-импорт из снимков побайтно воспроизводит все файлы каталога. |
| Совместимость перехода | Прежнее изменение архивировано с `--skip-specs`. Тест `module_one_update_preserves_legacy_choice_and_personal_data_on_two_startups` проверяет старый выбранный id, пользовательские правки и личный набор после двух запусков. |
| Границы архитектуры и установка | 18 архитектурных тестов. Обе release-команды установлены во временный Cargo root и открыты из изолированного окружения. Проверены `cargo run --locked` и `cargo run --locked --bin wpm-es`. |
| Навигация, центрирование, отсутствие новых слов и размеры окна | Терминальные тесты `spanish_course` проверяют центрирование на разных ширинах, все модули и границы поздних тем. `check_dataset_build.py` проверяет живое изменение размера, изолированный запуск, темы без новых слов и недоступный словарь при непустом соседнем разделе. |
| Восстановление и отказ записи | Проверены возврат в модуль, перезапуск, принудительное завершение процесса, неизвестный id, повреждённый файл и ошибка записи. Отдельный storage-тест сверяет байты прежнего файла после искусственной ошибки записи временного файла. |
| Тренировка и экзамен | PTY проверяет исправление ввода, скрытый ответ, пропуск, 0 %, частичный и полный результат, повтор, тренировку ошибок и достижимость последнего исправления после длинного ответа. Модельные тесты проверяют диакритику, нормализацию, альтернативы и перестановку без дублей. |
| Автономная поставка | Проверены комплект файлов Cargo-пакета, сборка при замене и удалении ресурсов и запуск установленного `wpm-es` без ресурсов рядом. Проверка A1–C2 сохраняет прежние 5 675 лемм. |

Все 11 новых сценариев курса и сценарий перехода старой базы успешно запускались по точным именам. Исправления переводов и соответствия словоформ зафиксированы в исходных решениях нормализации. Проверка полноты относится к снимку Duome от 17 ноября 2026 года; независимая экспертная редактура каждого перевода не проводилась.

`cargo test --locked --test e2e` и `cargo test --locked --all-features --all-targets` прошли. В каждом прогоне успешно выполнен 71 терминальный сценарий. Полный прогон также выполнил 22 библиотечных, 18 архитектурных и 2 теста формата. Строгая проверка OpenSpec прошла.
