# Proposal

## Why

На текущем Mac обычный `cargo run` выбирает SDK macOS 27, который установленный линковщик не обрабатывает (`unknown arm64e.x1-macos`). С доступным SDK macOS 15.4 запуск уже подтверждён, но пользователю приходится каждый раз задавать `SDKROOT` вручную.

## What Changes

- Настроить SDK по умолчанию для Cargo только в текущем checkout через локальный `.cargo/config.toml`, не требуя `export SDKROOT` перед запуском.
- Исключить именно `/.cargo/config.toml` из Git, чтобы абсолютный путь этого Mac не переносился на другие машины.
- Добавить краткую инструкцию для разработчика: где хранится локальное переопределение, как выбрать установленный совместимый SDK и как удалить настройку после исправления toolchain.
- Сохранить приоритет явно заданного пользователем `SDKROOT`; не менять Xcode, лицензию, системный выбор developer directory, shell profile и глобальную конфигурацию Cargo.

## Capabilities

### New Capabilities

Нет. Изменение относится к локальному инструментарию разработки, поэтому `.openspec.yaml` содержит `skip_specs: true`.

### Modified Capabilities

Нет. Способы установки и поведение `wpm` не меняются.

## Impact

Отслеживаемые файлы реализации: `.gitignore` и небольшой раздел README. Локальный неотслеживаемый файл: `.cargo/config.toml`. Изменения кода, зависимостей, CI и других OpenSpec changes не требуются. Проверка — запуск обычного `cargo run` в терминале без внешнего `SDKROOT`, успешная свежая сборка и существующие тесты; новые продуктовые E2E не нужны.
