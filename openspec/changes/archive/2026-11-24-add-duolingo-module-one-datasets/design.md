# Design

## Context

Descriptors автоматически обнаруживаются сборкой. Отсутствующий id добавляется в SQLite, существующие строки не перезаписываются. Профиль `spanish-phrases` поддерживает слова и выражения без пунктуации; закрытая схема не допускает поля происхождения. UI показывает id наборов. Мотивация описана в proposal.md.

Доступный https://duome.eu/vocabulary/ru/es/skills содержит словарь «испанский с русского», сгруппированный по нужным разделам. Это публичный сторонний словарь, не экспорт всех упражнений. https://duolingodata.com/dat/esfru131.html фиксирует структуру от 2025-05-09, но не словарь. Версии этих свидетельств нельзя отождествлять.

## Goals / Non-Goals

**Цели:** добавить десять разделов последовательно, сохранить происхождение каждой единицы и существующие данные.

**Вне рамок:** полный корпус упражнений как условие выпуска, обещание официальности/полноты курса, замена старого кафе, изменения UI/схемы descriptor, автоматическая лемматизация без проверки, сетевые запросы при запуске.

## Decisions

### 1. Доступный словарь вместо блокирующего полного экспорта

Основной материал — первые десять соответствующих разделов Duome `/vocabulary/ru/es/skills`. Зафиксировать дату получения и доступный состав. Все исходные записи этих разделов должны получить решение: включение, нормализация, повтор или обоснованное исключение. Это проверяемое покрытие доступного списка, а не заявление обо всех словах во всех упражнениях. Ранее найденные пользовательские карточки допустимы как вспомогательная сверка, но не заменяют привязку к разделу и не добавляются по тематической догадке.

Порядок id с префиксом `ru_es_duolingo_m1_s`: `01_cafe`, `02_greetings`, `03_origin`, `04_family`, `05_character`, `06_location`, `07_city`, `08_languages`, `09_weather`, `10_fruit`. Названия: «Заказывайте в кафе», «Приветствуйте и прощайтесь», «Ser de для указания происхождения», «Представьте семью и друзей», «Описывайте характеры», «Используйте estar для местоположений», «Говорите о местах в городе», «Говорите о языках», «Используйте hace для описания погоды», «Покупайте фрукты».

Альтернатива ждать официальный полный экспорт отвергнута по приоритету пользователя получить доступные данные сейчас. Наборы добавляются по порядку, каждый с собственной проверкой; результат этой итерации — все десять.

### 2. Свидетельство отдельно от descriptor

Хранить компактный машиночитаемый файл рядом с данными/документацией. Источник: URL, дата доступа, известная версия либо «неизвестно», тип материала, ограничение покрытия. Исходная запись: раздел, исходная форма/перевод, решение и причина. Опубликованная запись: dataset id, entry id, target, ru и связь с исходными записями. Повторы ссылаются на каноническую запись раннего раздела; исключения содержат причину.

При ручной сверке проверять испанское написание, диакритику, лемму и русский перевод; спорные переводы сверять по словарным/справочным источникам с указанием ссылки. Ошибочный перевод не копируется лишь потому, что он есть в Duome. Неразрешённую неоднозначность явно исключать. Проверка свидетельства сопоставляет все решения с доступным составом источника и descriptors.

### 3. Нормализация и дедупликация

Словоформы сводятся вручную к лемме (`soy`/`es` → `ser`), согласованные и множественные формы объединяются. Изолированные существительные с артиклем нормализуются к существительному. Явно представленные выражения остаются отдельными единицами; их составляющие не извлекаются автоматически как дополнительные карточки. Нормализуются пробелы и пунктуация согласно профилю, сохраняется диакритика и согласованный регистр.

Ключ повторов — NFC target в нижнем регистре после лемматизации; диакритика сохраняет различие (`si`/`sí`). Каждая единица принадлежит самому раннему подтверждённому разделу по порядку источника. Слова внутри различных выражений могут повторяться. Дедупликация ограничена десятью новыми наборами, прежние кафе и A1–C2 не исключают слова из них.

### 4. Достаточно существующей загрузки

Использовать schema_version 1, profile `spanish-phrases`, level `beginner`, стабильные entry id и описание «предварительный набор по публичному словарю; полнота курса не подтверждена». Сохранить все прежние descriptors и настройки, не фильтровать локальные наборы. Первый новый descriptor увеличивает каталог до 20, десятый — до 29.

### 5. Проверять содержимое и наблюдаемое поведение отдельно

Общие parser/build tests и E2E автообнаружения уже применяются к новым descriptors. Дополнить только недостающие сценарии выбора/запуска и сохранности прежнего выбора при двух запусках. Небольшая проверка свидетельства подтверждает соответствие записей, обработку каждого исходного слова и отсутствие повторов. Существующий валидатор A1–C2 не ослабляется. Лингвистическая сверка проводится вручную: терминальный тест не доказывает значение слова.

## Risks / Trade-offs

- Сторонний словарь может быть неполным или отличаться от курса пользователя → явно указать источник, дату и пределы покрытия.
- Переводы/словоформы источника могут ошибаться → ручная сверка и обоснованные исключения.
- Более поздний источник может изменить распределение → не переписывать установленную SQLite молча; корректировка опубликованных данных потребует отдельного решения о миграции.

## Migration Plan

1. Зафиксировать материал десяти разделов и правила нормализации.
2. По порядку добавлять каждый набор с соответствующим свидетельством и проверкой, начиная с кафе и приветствий.
3. Проверить весь выпуск в чистой и прежней базе; старый выбор и записи сохраняются.
4. Откат к прежнему бинарнику не требует удаления новых строк; разрушительных миграций нет.
