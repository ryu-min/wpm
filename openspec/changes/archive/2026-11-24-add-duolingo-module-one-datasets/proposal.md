# Proposal

## Why

Текущий `ru_es_cafe_beginner` — тематическая подборка из 31 пары, а не проверенный словарь модуля Duolingo «Испанский с русского». Пользователю нужны наборы по разделам без повторов уже сейчас; найденный публичный словарь Duome позволяет добавить их без ожидания полного экспорта упражнений.

## What Changes

- Последовательно добавить десять наборов первого модуля на основе доступных записей https://duome.eu/vocabulary/ru/es/skills: кафе, приветствия, происхождение, семья, характер, местоположение, город, языки, погода, фрукты. Каждый готовый набор можно проверять и использовать до окончания остальных.
- Сохранить `ru_es_cafe_beginner`, его 31 пару, доступность и сохранённый выбор. Новые наборы дополняют прежние 19; после выпуска десяти каталог содержит 29 наборов.
- Для каждой опубликованной единицы зафиксировать источник, раздел, исходную форму, нормализацию и русский перевод. Сверить написание, лемму и перевод; явно учитывать исключения.
- Объединять словоформы в леммы и не повторять канонические единицы между новыми разделами; сохранять явно представленные источником выражения.
- В описаниях и документации обозначить наборы как предварительные по публичному словарю. Не заявлять официальность, полный корпус упражнений либо точное совпадение содержимого со снимком структуры от 2025-05-09.

## Capabilities

### New Capabilities

- `duolingo-spanish-module-one-datasets`: наборы десяти разделов с проверяемым происхождением, явными границами покрытия и дедупликацией.

### Modified Capabilities

- `exercise-modes`: расширение встроенного каталога с сохранением существующих наборов, данных и выбора пользователя.

## Impact

JSON descriptors в `resources/datasets/`, свидетельство происхождения, документация и проверки содержимого/терминальные E2E. Используются существующие обнаружение, встраивание, добавление отсутствующих наборов в SQLite и режим Translation. Изменения схемы descriptor, реестра, UI, старого кафе и настроек не требуются.

Расположение словаря в приложении заменено изменением `add-spanish-course-app`. Исходные записи и решения первого модуля перенесены в общий каталог курса.
